# OneBookOS Website

The public website for the independent OneBookOS Linux project.

## Hosting

This is a zero-dependency static HTML/CSS/JS website. Vercel project settings: **Framework: Other**, **Root Directory: website**, and no build command. It can use the free vercel.app subdomain.

Downloads use the public GitHub Releases API for Nexora-Tech26/OneBookOS. The ISO, SHA256 checksum, release label and file size are derived from published release assets, not invented.

Gallery images are marked as **design concepts**. No illustrations are presented as real screenshots of the operating system.
